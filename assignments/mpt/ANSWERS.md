# 作業二：Opportunity Set 與最小變異數投資組合（MVP）結果與回答

## 資料與方法

- 資料來源：TEJ 調整股價（日），除權息調整後收盤價。
- 期間：2019-01-02 至 2026-10-05，共 1,883 個交易日，1,882 筆日報酬。
- 8 檔資產：0050、0056、00646（股票 ETF）、00679B、00720B（債券 ETF）、00635U（黃金）、1216（統一）、2412（中華電）。
- 方法：日報酬使用簡單報酬率（`pct_change()`），年化以 252 個交易日計算，標準差與共變異數為樣本統計量。
- 程式：`mpt_analysis.py`（Part I、II）與 `mpt_portfolio.py`（Part III）。所有結果檔放在 `results/`，用 README 的指令可重現。

缺值處理：依日期排序後，只在資產有資料的期間內向前填補單日缺口，不做向後填補，並取所有資產共同有資料的期間。

## Q1：哪些資產之間的相關性最高？

0050 與 0056 相關性最高（0.80）。兩者都是台灣股票 ETF，成分股高度重疊（台積電等大型權值股），所以走勢很接近。

其次是 00679B 與 00720B（0.74），一個是美國公債 ETF，一個是美國投資等級公司債 ETF，兩者都受美國利率影響。再來是 0050 與 00646（0.61）、0056 與 00646（0.56），台股與美股大型股同受全球股市與科技類股的影響。

這幾組資產放在一起分散效果有限。

## Q2：哪些資產之間相關性低或為負？

只有 00679B（美國 20 年期以上公債）與其他資產出現負相關：與 0050 為 -0.09、與 00646 為 -0.06、與 2412 為 -0.04、與 0056 為 -0.04、與 1216 為 -0.03。

其他接近零的組合有 00720B 與 2412（0.04）、黃金 00635U 與 2412（0.06）、00635U 與 1216（0.08）、00720B 與 1216（0.08）。長天期公債與黃金的行為和股票不同，防禦型的中華電（2412）與其他資產連動也低。

28 組資產配對的平均相關係數為 0.22。

## Q3：哪一種組合的分散效果最好？

股票（0050、0056、00646）搭配 00679B 的風險降低效果最明顯，因為 00679B 與這些股票都是小幅負相關。再加入 2412 和黃金 00635U 會更分散，因為它們波動較低，或與多數資產的相關性接近零。

兩檔股票 ETF（相關 0.80）和兩檔債券 ETF（相關 0.74）不應視為各自獨立的分散來源。

最小變異數投資組合驗證了這個結論（`results/mvp_weights.csv`、`results/mvp_summary.csv`）：

| | 封閉解（可放空） | 不可放空 |
|---|---|---|
| 2412 | 43.0% | 43.3% |
| 00679B | 25.6% | 26.0% |
| 0056 | 16.0% | 9.8% |
| 00646 | 9.4% | 7.3% |
| 00635U | 9.2% | 8.8% |
| 1216 | 4.4% | 4.3% |
| 0050 | -7.2% | 0% |
| 00720B | -0.3% | 0.5% |
| 預期報酬（日均 x 252） | 7.67% | 8.15% |
| 波動度 | 7.47% | 7.53% |

- 封閉解為 w = Σ⁻¹1 / (1ᵀΣ⁻¹1)，負權重表示放空；不可放空版本用數值最佳化（SLSQP，權重介於 0 到 1、總和為 1）。
- MVP 波動度 7.5%，低於波動最低的單一資產 2412（10.6%），也低於等權重組合（9.4%）。
- 分散化比率（資產波動度加權平均 / 組合波動度）：不可放空 MVP 為 1.83，等權重為 1.73。
- 封閉解只需要對 0050 與 00720B 小幅放空，所以不可放空版本只多出約 0.05 個百分點的波動度，幾乎沒有損失。

## 限制與注意事項

- 預期報酬使用歷史平均，這段期間台股漲幅很大（0050 的 CAGR 為 30.8%），不代表未來。MVP 只取決於共變異數矩陣，不依賴預期報酬。
- 00679B 是這份樣本中唯一對股票呈負相關的資產，壓力時期相關性可能改變。
- 圖中的 Sharpe 比率僅用於顏色深淺（無風險利率設為 0）。
